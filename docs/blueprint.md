# **App Name**: ScoutPro

## Core Features:

- Vertex AI Executive Summary: An AI tool that synthesizes scout ratings and textual notes to generate objective summaries and eliminate subjective bias.
- Tactical Role Firestore Engine: Cloud-based persistent storage utilizing Firestore to synchronize role-specific KPIs for positions like Mezzala or False 9 across devices.
- Interactive Tactical Canvas: A refined SVG-based pitch interface for drawing movement vectors, heatmaps, and spatial notes during live matches.
- PIM Analytics Tool: A reasoning tool using Cloud Functions and AI to calculate the Player Impact Metric (PIM) by benchmarking performance against historical club data.
- Intelligent Voice Dictation: An AI-powered voice-to-text tool that uses natural language processing to structure verbal observations into specific match report fields.
- Collaborative Team Dashboard: Multi-role workspace for directors and scouts to manage player 'Grades' (A to D) and share interactive feedback in real-time.
- Professional Export Suite: Automated generation of elite-level scouting PDFs, Excel reports, and interactive web-based executive dashboards.

## Style Guidelines:

- Primary: Deep Navy (#1B263B) for a professional and institutional feel.
- Secondary/Highlight: Golden Harvest (#E0B050) representing elite performance and prestige.
- Accent: Tech Teal (#48CAE4) used specifically for data visualizations and tactical vectors.
- Headlines use 'Space Grotesk' for a modern, technical aesthetic; Body text uses 'Inter' for high legibility in field reports.
- Thin-line precision icons that mirror technical football diagrams and tactical symbols.
- A multi-tab interface optimized for 10-inch tablets with large touch targets for matchday input.
- Fluid SVG path animations for drawing tactical movements and subtle fade-ins for metric dashboard transitions.
