# Manual de Usuario Detallado - ScoutPro 360 Football

Bienvenido a la guía maestra de **ScoutPro 360**. Este documento está diseñado para que los administradores y usuarios de élite comprendan el funcionamiento técnico y estratégico de cada sección de la plataforma.

---

## 1. Centro de Mando (Dashboard)
*   **Objetivo**: Obtener una "Conciencia Situacional" inmediata de las operaciones de captación del club.
*   **Funcionamiento para el usuario**:
    *   **KPIs de Rendimiento**: En la parte superior, el usuario puede ver el total de jugadores en la base de datos, informes que requieren atención inmediata y el PIM promedio de la plantilla actual del club.
    *   **Top Targets (Grado A)**: Es una lista filtrada automáticamente que muestra solo a los jugadores con potencial de "Fichaje Inmediato". El usuario puede pulsar en cualquier jugador para ver su perfil completo.
    *   **Actividad Reciente**: Un feed en tiempo real que muestra qué otros scouts están trabajando y qué informes se han finalizado en las últimas 24 horas.
*   **Resultado**: Optimización del tiempo. El usuario sabe a quién debe vigilar hoy sin perderse en menús complejos.

## 2. Informe en Vivo (Live Report)
*   **Objetivo**: Estandarizar la toma de datos durante los partidos, eliminando la subjetividad del papel y lápiz.
*   **Funcionamiento para el usuario (Flujo de 9 pasos)**:
    1.  **Jugador**: El usuario introduce datos básicos y utiliza el **Pizarra Táctica** para marcar con un clic la zona exacta donde el jugador está operando.
    2.  **Contexto**: Se define si el partido es de alta intensidad, el clima y el sistema táctico del rival. Esto permite a la IA entender si el jugador rinde bajo presión o en condiciones adversas.
    3.  **Módulos de Evaluación (Técnico, Táctico, Físico, Mental)**: Para cada métrica, el usuario puntúa de 1 a 5. **Clave**: Se recomienda añadir una nota rápida en el campo de texto para justificar la puntuación (ej: "Excelente pie débil en salida").
    4.  **Acciones**: Durante el partido, el usuario añade eventos clave (minuto, acción, resultado). Esto crea una línea de tiempo del impacto real del jugador.
    5.  **IA Analytics**: Al final, el usuario pulsa **"Calcular PIM"**. La IA analiza los +50 datos introducidos y genera una puntuación de 0 a 100 y un resumen profesional automático.
*   **Resultado**: Un informe técnico de nivel profesional, listo para exportar a PDF para la Dirección Deportiva.

## 3. Base de Datos Global
*   **Objetivo**: Mantener el "Patrimonio de Inteligencia" del club centralizado y accesible.
*   **Funcionamiento para el usuario**:
    *   **Búsqueda Avanzada**: El usuario puede escribir "Delantero", "Brasil" o el nombre de un club para filtrar instantáneamente entre miles de perfiles.
    *   **Gestión de Estatus**: Los jugadores se categorizan como "Prioridad", "Monitoreado" o "Élite". El usuario puede cambiar estos estados para organizar su propio flujo de trabajo.
    *   **Exportación**: Con un clic en "Exportar CSV", se puede descargar la lista filtrada para reuniones de comité de fichajes.
*   **Resultado**: Recuperación instantánea de información histórica. Se evita que el conocimiento "se vaya" cuando un scout deja el club.

## 4. Mapeo de Talento (Talent Mapping)
*   **Objetivo**: Análisis geográfico estratégico para decidir dónde invertir los recursos de viaje.
*   **Funcionamiento para el usuario**:
    *   **Regiones Prioritarias**: El usuario analiza la lista de países y ligas. Si ve que "Brasil Serie A" tiene un **AVG PIM** de 74, sabrá que es una zona de alto retorno de inversión.
    *   **Logística de Scouting**: Muestra datos operativos como horas de vuelo acumuladas y scouts activos en cada zona.
*   **Resultado**: Eficiencia presupuestaria. El club envía scouts a donde los datos dicen que está el talento, no por intuición.

## 5. Hub de Analítica
*   **Objetivo**: Transformar datos individuales en tendencias de rendimiento organizacional.
*   **Funcionamiento para el usuario**:
    *   **Tendencias PIM**: Un gráfico de área muestra si el talento que estamos encontrando es mejor cada mes. Si la línea sube, el departamento de scouting está mejorando sus filtros.
    *   **Matriz de Productividad**: Compara cuántos informes hace cada scout vs. la calidad (PIM) de los jugadores que encuentra.
*   **Resultado**: Evaluación del desempeño del propio departamento de scouting.

## 6. PIM Benchmarking
*   **Objetivo**: Validar si un posible fichaje es realmente mejor que lo que ya tenemos.
*   **Funcionamiento para el usuario**:
    *   **Comparación Cara a Cara**: El usuario selecciona a un prospecto (izq) y la plataforma lo enfrenta automáticamente contra el **"Squad Benchmark"** (el promedio de los jugadores actuales del club en esa posición).
    *   **Delta PIM**: Si el Delta es +12.0, significa que el prospecto mejorará la plantilla en un 12%.
    *   **Compatibilidad**: Un porcentaje de ajuste que indica si el estilo del jugador encaja con la filosofía del entrenador.
*   **Resultado**: Reducción drástica del riesgo de error en fichajes costosos.
