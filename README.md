
# ScoutPro 360 Football

AI-Powered Professional Football Scouting Platform.

## GitHub Repository
Este proyecto está conectado con el perfil de GitHub de **FutsalDex**:
[https://github.com/FutsalDex/scoutpro360](https://github.com/FutsalDex/scoutpro360)

## Descripción
ScoutPro 360 es una plataforma avanzada diseñada para departamentos de scouting profesionales, integrando inteligencia artificial para el análisis de jugadores y benchmarking táctico.

## Tecnologías
- **Next.js 15** (App Router)
- **Firebase** (Auth, Firestore)
- **Genkit** (Google Gemini AI)
- **Tailwind CSS** & **ShadCN UI**

## Guía de Sincronización con GitHub (Terminal)
Para subir tus cambios por primera vez:
1. `git init`
2. `git add .`
3. `git commit -m "primer commit"`
4. `git branch -M main`
5. `git remote add origin https://github.com/FutsalDex/scoutpro360.git`
6. `git push -u origin main`

Para subir cambios posteriores:
1. `git add .`
2. `git commit -m "descripción del cambio"`
3. `git push origin main`
